# GrünFahrt Rider App

Eine moderne Flutter-App für Gernans ride-sharing Platform. Die App engält Fahrgiäste, live-Tracking, Zahlungsinntegration, Sprichassistent und deutsche Lokalisierung.

## Funktionen

- 🎷 **Map-Integration** - Google Maps mit Standortsuche und Routen
- 🎙 **Fahrginstannen'suche** - Verfögbare Buchung mit Fahrzeilen-Anzeige
- 🎮 **Live-Tracking** - Realtime-Fahrtstracking mit Driver-Infos
- 💪 **Zahlungens** - Stripe-Integration mìt Kartenzahlung und SEPA-Lastschrift
- 🎺 **Sprichassistent** - Stimme-steuerung und Text-to-Speech
- 🔦 **Push-Notificationen** - Firebase Cloud Messaging
- 💖 **Deutsche UI** - Vollständig deutsch sprachige UI, PBefG-konform
- 🎮 **Barerkfreiheit** - Screen Reader, highe Kontrasten, erste Hilfe
