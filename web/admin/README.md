 GruenFahrt Admin Dashboard

Admin Dashboard für die deutsche Ride-Sharing Platform GruenFahrt.

## Features

- **Bemutzerverwaltung**: Verwalten von Fahrern, Fahrgästen und Administratoren
- **Fahrer-Verifizierung**: Dokumentenprüfung und Freigabe
- **Fahrt-Monitoring**: Echtzeit-Überwachung aller Fahrten
- **Analytics**: Umfa_sende Berichte und Statistiken
- **Deutsche Lokalisierung**: Vollst�ndig auf Deutsch

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Zustand (State Management)
- React Query (Data Fetching)
- Recharts (Charts)
- Socket.io (Real-time)
- i18next (Internationalization)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Environment Variables

```
VITE_API_URL=https://api.gruenfahrt.de/v1
VITE_WS_URL=wss://ws.gruenfahrt.de
```
